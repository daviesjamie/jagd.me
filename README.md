# jagd.me

This is the source for [jagd.me](https://jagd.me/).

It's a straightforward [Hugo](https://gohugo.io) site, using a custom theme/layout that's loosely based on [Hugo Bear Blog](https://themes.gohugo.io/themes/hugo-bearblog/) and the [Rose Pine palette](https://rosepinetheme.com/palette/).

All CSS is vanilla and there's no JavaScript.

```sh
# Run a development server
❯ hugo server

# Run a development server and include all draft pages/posts
❯ hugo server -D
```
